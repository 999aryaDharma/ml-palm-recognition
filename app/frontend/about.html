PalmID

Sistem biometrik pengenalan telapak tangan berbasis Deep Learning dengan arsitektur web client-server. Dibangun menggunakan MobileFaceNet + ArcFace untuk menghasilkan identifikasi yang akurat, cepat, dan tanpa sentuhan.

~150ms Latensi Contactless 128-d Embedding
ARCHITECTURE

Arsitektur Sistem

PalmID memisahkan Offline Training Pipeline (proses pelatihan model satu kali) dan Runtime Inference (pengenalan waktu-nyata). Frontend menangkap gambar melalui Webcam API, mengirimnya ke backend FastAPI via HTTP REST, lalu backend menjalankan seluruh pipeline ML dan mengembalikan hasil identifikasi.

01

Hand Detection & Quality Gate

MediaPipe Hand Landmarker mendeteksi 21 titik koordinat tangan secara real-time. Sebelum lanjut, sistem menjalankan quality gate ketat untuk memastikan data yang masuk berkualitas tinggi.

Quality Gate Checks:
• Visibility ≥ 0.5 untuk semua 21 landmark
• Palm menghadap kamera (heuristik depth MCP vs TIP landmark 9 & 12)
• Ukuran tangan ≥ 25% diagonal frame
• Laplacian variance ≥ 50 (deteksi blur)
MediaPipe Python 21 Landmarks 3D Heuristic
02

ROI Extraction (Region of Interest)

Mengekstrak area telapak tangan yang relevan secara geometris. Valley line ditarik antara landmark 5 (pangkal telunjuk) dan 17 (pangkal kelingking), lalu di-offset 30% ke arah pergelangan (landmark 0) sebagai pusat ROI.

Proses Geometris:
• Hitung sudut rotasi dari valley line (atan2)
• Gunakan cv2.warpAffine untuk rotasi gambar
• Crop persegi dengan sisi = 1.2× panjang valley line
• Resize ke 112×112 piksel RGB standar
OpenCV Affine Transform Landmark Geometry
03

Feature Embedding (Deep Learning)

Gambar ROI 112×112 dilewatkan melalui model MobileFaceNet yang telah di-fine-tune dengan ArcFace Loss pada dataset Tongji. Outputnya adalah vektor numerik 128 dimensi yang merepresentasikan identitas unik pola garis telapak tangan — ibarat "sidik jari digital" dalam ruang matematis.

Model Architecture:
• Backbone: MobileFaceNet (pretrained MS-Celeb-1M)
• Loss: ArcFace (s=64, m=0.5) — angular margin metric learning
• Output: 128-dim L2-normalized embedding vector
• Inference: TorchScript (.pt) di CPU/GPU
MobileFaceNet ArcFace Loss PyTorch 128-dim
04

Cosine Similarity Matching

Vektor embedding baru dibandingkan dengan seluruh template yang tersimpan di database menggunakan Cosine Similarity. Untuk setiap pengguna, diambil rata-rata dari top-3 skor tertinggi (multi-template averaging) agar hasil lebih stabil. Jika skor terbaik ≥ threshold kalibrasi, identitas dikenali.

Matching Strategy:
• Untuk tiap user: hitung cosine(query, setiap template)
• Urutkan descending, ambil rata-rata top-3
• Pilih user dengan skor tertinggi
• Jika skor ≥ threshold → status: "identified"
• Jika skor < threshold → status: "unknown"
Cosine Similarity Multi-template K-NN Threshold Calibration
MODEL TRAINING

Proses Pelatihan Model

Model dilatih menggunakan dataset Tongji Contactless Palmprint Database (12.000 gambar, 300 individu) dengan protokol cross-session: 200 individu untuk training (sesi 1) dan 100 individu untuk evaluasi hold-out (sesi 2).

Phase 0 — Smoke Test

Validasi pretrained MobileFaceNet (MS-Celeb-1M) pada sampel Tongji. Memastikan backbone dapat menghasilkan embedding yang bermakna sebelum fine-tuning.

Phase 1 — Softmax Warm-up

Fine-tune dengan standard Cross-Entropy Loss selama beberapa epoch awal. Tujuannya agar weight model beradaptasi ke domain palmprint sebelum dioptimasi dengan metric learning.

Phase 2 — ArcFace Fine-tuning

Ganti loss function ke ArcFace (s=64, m=0.5) — menambahkan angular margin di ruang embedding sehingga vektor dari kelas yang sama semakin rapat, dan vektor antarkelas semakin terpisah jauh.

Phase 3 — Evaluasi & Kalibrasi

Evaluasi pada hold-out test set (100 individu, sesi 2). Hitung metrik biometrik (EER, TAR@FAR, ROC AUC). Kalibrasi threshold optimal dari kurva FAR/FRR.

Phase 4 — Export TorchScript

Model final diekspor ke format TorchScript (.pt) untuk deployment di backend FastAPI. File threshold.json menyimpan parameter kalibrasi.
